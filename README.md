# Pronósticos ⚽

Pronósticos estadísticos de LaLiga, Premier League, Bundesliga y Ligue 1, con seguimiento de aciertos.

- **Web:** https://fau25.github.io/pronosticos/
- Se actualiza sola cada mañana (GitHub Actions → `.github/workflows/actualizar.yml`): descarga resultados de football-data.co.uk y Understat, recalcula pronósticos y marca ✓/✗ en los partidos jugados.
- Para lanzarla a mano: pestaña **Actions → Actualizar pronósticos → Run workflow**.

Los pronósticos de días ya jugados se calculan solo con los partidos anteriores a ese día. Son probabilidades, no certezas. +18 · Juega con responsabilidad.
